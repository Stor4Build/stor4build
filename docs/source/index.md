# Stor4Build Documentation

Stor4Build is a Python package and command line tool for simulating building-integrated thermal energy storage systems with EnergyPlus and OpenStudio.

This documentation is organized around stable user workflows first, with generated reference material for the CLI, Python package, and web API schema. The Python API is expected to evolve, so the durable guidance should live in tutorials, how-to guides, examples, and model/output references.
